# 仰韶 · 个人作品集网站

这是一个**个人作品展示网站**：右上角有导航栏，分为 **首页 / 图片 / 视频 / 文章 / 关于我 / 联系我**
六个页面（点导航会**真正进入新页面**，网址会变），首页是一张铺满屏幕的风景背景图，
深色氛围风格，手机和电脑都能正常看。

> 本页内容是**演示用的假数据**（占位内容），用来先看效果。
> 你把 `src/data/works.js` 里的文字换成自己的作品，网站就变成你的了。

## 一、第一次怎么跑起来（看效果）

> **如果你看到"'npm' 不是内部或外部命令"**——别慌，说明你电脑里有 Node，但 cmd 不知道去哪找。直接用这个文件夹里的 **「安装依赖.bat」** 和 **「启动网站.bat」** 即可，不用去改系统设置。

1. 打开文件夹：`E:\代码成品\网站项目\个人作品集`

### 方法 B：手动敲命令（适合想学习）

#### 1. 准备：确认电脑里有 Node

网站需要 **Node.js**（一个运行网页程序的工具，免费）。

本项目已经使用电脑里现成的 Node 版本，**一般不用你额外安装**。

想确认有没有，可以打开「命令提示符」敲一句：

```
node -v
```

如果显示类似 `v22.22.2` 这样的版本号，就说明没问题。

> 如果提示"不是内部或外部命令"，说明电脑没装 Node。
> 去 <https://nodejs.org>（Node 官网）下载带 **LTS** 字样的安装包，一路点"下一步"装完即可。
>
> 如果你**确定已经有 Node 但还是报错**，请参考上面的「方法 A：双击脚本」。

#### 2. 打开项目文件夹

在文件资源管理器里进入：

```
E:\代码成品\网站项目\个人作品集
```

在**地址栏**里输入 `cmd` 然后按回车 —— 这样会直接在当前文件夹打开一个黑色命令窗口。

> 这一步很关键：**命令窗口要开在项目文件夹里**，后面的命令才能生效。

#### 3. 安装"依赖"（只需做一次）

> **依赖**：网站用到的一些现成代码包。第一次要下载一次，以后不用再下。

在黑色窗口里敲：

```
npm install
```

按回车，等它跑完（第一次大约 1~2 分钟，会刷一堆字，正常）。
出现 `added xxx packages` 就是成功了。

> 本项目的缓存已经设置成下载到 **E 盘**（不会占 C 盘），你不用管。
>
> 如果这里提示 `'npm' 不是内部或外部命令`，说明你的 Node 路径没加到系统里。最简单的方法就是关掉这个窗口，**回去用「方法 A：双击脚本」**。

#### 4. 启动网站

```
npm run dev
```

跑起来后会显示一行地址，类似：

```
Local    http://localhost:4321/
```

#### 5. 在浏览器里打开

复制上面那行地址（`http://localhost:4321`），粘到浏览器（Chrome / Edge 都行）地址栏，回车。

**看到网站了 ✅**

> **`localhost`** 就是"你自己的电脑"的意思；**`4321`** 是这个网站用的"门牌号"，
> 不同程序用不同门牌号，避免撞车。

#### 6. 想关掉网站

回到那个黑色命令窗口，按键盘 **`Ctrl + C`**（同时按住 Ctrl 再按 C），网站就停了。
或者直接关掉窗口也行。

## 二、怎么改作品内容（最常用）

**所有内容都放在这一个文件里**：

```
src\data\works.js
```

用记事本、VS Code 或任何文本编辑器打开它，改完**保存**，
浏览器里的页面会**自动刷新**，马上看到变化（不用重启命令）。

### 文件里都有啥

| 位置 | 管什么 |
|---|---|
| `site` | 顶部名字「仰韶」、一句话介绍 |
| `navItems` | **右上角导航菜单**（菜单名字和指向的页面） |
| `about` | **「关于我」页面的整段自我介绍文案** + 信任区资料（`about.profile`） |
| `platforms` | **视频页顶部的多平台入口**（B 站 / 抖音 / 小红书链接） |
| `videos` | 影像区的 3 个视频卡片 |
| `articles` | 文字区的长文章 |
| `quotes` | 文字区的短句子 |
| `photos` | 摄影区的图片 |
| `contact` | 底部 / 联系我页 的联系方式、版权 |

### 例子：加一部新短片

打开 `works.js`，找到 `videos` 那一段（开头是 `export const videos = [`），
在它下面的 `[` 和 `]` 之间，照着已有的一条，抄一条新的，注意**结尾要有英文逗号**：

```js
{
  title: '我的新片子',            // 标题
  duration: '03:20',              // 时长
  year: '2025',                   // 年份
  description: '一句话简介。',     // 卡片上的介绍
  gradient: 'linear-gradient(145deg, #1c2530 0%, #0f1419 100%)',  // 封面颜色
},
```

保存后，影像区就会多出一张卡片。

> 加文字、加短句、加图片，都在文件**最末尾有完整示例**，照着抄就行。

## 二·补、怎么改导航菜单 / 换首页背景图

### 改导航菜单（右上角那六个字）

打开 `src\data\works.js`，找到 `navItems` 那一段：

```js
export const navItems = [
  { label: '首页',   href: '/',         match: '/' },
  { label: '图片',   href: '/photos',   match: '/photos' },
  { label: '视频',   href: '/videos',   match: '/videos' },
  { label: '文章',   href: '/writings', match: '/writings' },
  { label: '关于我', href: '/about',    match: '/about' },
  { label: '联系我', href: '/contact',  match: '/contact' },
];
```

- `label` 是**菜单上显示的字**，想改名字只改这个（比如把"关于我"改成"关于"）。
- 想**调整顺序**，就把整行上下移动。
- `href` / `match` 是它指向哪个页面，**一般不用动**。

### 换首页背景图（换成你自己的照片）

首页那张风景图，现在是**用代码画的**（抽象远山 + 晨雾），文件在：

```
public\hero-bg.svg
```

**想换成自己的照片**，按下面三步做（很简单）：

1. 准备一张**横向的风景照**（建议宽度 1920 像素以上，`jpg` 或 `png` 格式）。
2. 把照片放进 `public` 文件夹里，文件名改成 `hero-bg.jpg`。
3. 打开 `src\components\Hero.astro`，找到这一行：

   ```css
   background-image: url('/hero-bg.svg');
   ```

   把 `hero-bg.svg` 改成 `hero-bg.jpg`（也就是 `url('/hero-bg.jpg')`），保存即可。

> 代码里在那一行上方写了「**【替换背景图：改这里】**」的注释，照着找很快能找到。
> 图片会自动铺满整个屏幕，不用你调尺寸。

## 三、怎么改颜色 / 风格

颜色和动效都在这一个文件里：

```
src\styles\global.css
```

文件**最上面**有一块 `:root { ... }`，里面每个变量后面都写了中文注释。
改颜色只要改**颜色代码**（`#` 后面那串字符）即可，例如：

```css
--bg: #0a0a0c;        /* 页面底色（近黑） */
--accent: #8a94a6;    /* 主色：冷灰蓝 —— 想换主色改这里 */
--text: #e8eaed;      /* 主文字颜色 */
```

**怎么知道某个颜色对应什么颜色代码？**
搜"颜色代码表"或用在线取色工具（如 <https://www.colorhex.com>）挑一个色号，粘进去即可。

**想调动画快慢？** 看这两个：

```css
--dur-hover: 0.4s;   /* 卡片悬停亮起要多久 */
--breathe: 11s;      /* 背景呼吸一次的时间（数字越大越慢） */
```

> ⚠️ 颜色代码不要漏掉开头的 `#`，也不要少写或多写字符（一般是 6 位，如 `#8a94a6`）。

## 三·补、v2.2 新增：怎么改「关于我」信任区 / 平台链接 / 动效

这一版（v2.2）给网站加了三个小东西。除了"动效"在样式文件里，
其余内容**都只改 `src\data\works.js` 这一个文件**，保存后浏览器自动刷新。

### 1. 「关于我」页面新增的「信任区」

打开 `src\data\works.js`，找到 `about` 里面那段 `profile: { ... }`——

| 字段 | 管什么 | 怎么改 |
|---|---|---|
| `current` | 当前身份 | 改 `text`（一句话）；`tags` 是那几个小标签 |
| `timeline` | 走过的路（时间线） | `items` 里每条是 `{ year: '年份', text: '一行说明' }` |
| `collab` | 合作与露出（标签墙） | `items` 数组；有合作方再填，**宁可留「待补充」也别编** |
| `skills` | 擅长什么（标签） | `items` 数组 |
| `looking` | 想找什么 | 改 `text`（一句话意向） |

想加 / 删一个标签，就在对应的数组里加一行、删一行即可（**注意结尾的英文逗号**）。

### 2. 视频页顶部的「多平台入口」

打开 `src\data\works.js`，找到 `platforms`：

```js
export const platforms = [
  { label: 'B 站',   href: '', note: '待补充' },
  { label: '抖音',   href: '', note: '待补充' },
  { label: '小红书', href: '', note: '待补充' },
];
```

- 把你在该平台的**主页链接**粘进对应那一行的 `href` 里（用英文引号包住），保存后就变成**可点的按钮**（点开是新标签页）。
- `href` 留空 `''` 时，会显示成半透明的「待补充」**灰态、点不动**——这是正常的，不是坏了；填上链接就自动变可点。
- **抖音**要填「公开主页」链接（形如 `https://www.douyin.com/user/MS4wLjABAAAA...`）；
  带 `self?` 的那种是**登录态地址**，别人打不开，**不要填**。

### 3. 想调动效（滚动淡入 / 鼠标光点 / 悬停）

- 这一版新增了：**滚动时内容淡入**、**鼠标小光点**（移到卡片/按钮上会变成圆环）、**卡片悬停增强**。
- 它们的样式与快慢都在 `src\styles\global.css` 里，想调去那里改。
- 这些动效**会自动尊重系统设置**：如果系统开了"减少动态效果"，淡入、光点、卡片缩放都会自动关闭（不会晃眼）；
  触屏手机上也不会出现鼠标光点，系统原生光标始终保留。
- 不想让某块内容淡入？把那一行的 `data-reveal` 删掉即可。

## 五、常见问题

### Q1：提示端口被占用（`Port 4321 is in use`）怎么办？

「端口」= 上面说的"门牌号"。4321 被别的程序占了，换一个门牌号即可：

```
npm run dev -- --port 4322
```

然后浏览器打开 `http://localhost:4322`。

### Q2：`npm install` 很慢或卡住？

鼠标别动它，耐心等；实在卡住，按 `Ctrl + C` 停掉，重新敲一次 `npm install`。
（本项目的下载缓存存在 E 盘，重装会很快。）

### Q3：改完 `works.js` 页面没变化？

1. 确认**保存**了文件；
2. 确认改的是 `src\data\works.js` 这个文件；
3. 还不行就把命令窗口关掉，重新 `npm run dev`。

### Q4：`works.js` 改完报错了（页面白屏 / 命令窗口一堆红字）？

多半是**少写了逗号**或**引号没配对**（要用英文引号 `'` 不是中文引号 `‘`）。
把刚改的那一条，对着上面的例子逐字检查一遍，或先删掉刚加的那条再试。

### Q5：命令窗口里的字能看懂吗？

只记住这几句就够：

- `npm install` —— 装依赖（只做一次）
- `npm run dev` —— 启动网站
- `Ctrl + C` —— 关掉网站

关掉命令窗口，网站也就停了。

## 七、技术说明（给懂的人看）

- 框架：**Astro 4**（纯静态多页面输出，零 UI 库、零外部字体、零外部图片）
- 路由：`src/pages/` 下每个 `.astro` 文件对应一个真实 URL（多页面 `Mpa`），导航是**真实页面跳转**
- 样式：原生 CSS + CSS 变量主题，无 Tailwind
- 当前页高亮：`NavBar.astro` 用 `Astro.url.pathname` 对比 `navItems[].match` 加 `active` 类
- 封面占位：视频封面 / 摄影图片均由 CSS `linear-gradient` 生成
- 首页背景：`public/hero-bg.svg`（SVG 多层山影 + 渐变天空 + 雾气），`background-size: cover` 铺满
- 动效：CSS `@keyframes` 呼吸 + 原生 JS `requestAnimationFrame`（鼠标光晕 + 光点）+ `IntersectionObserver`（滚动淡入）
- 无 JS 兜底：滚动淡入的初始"隐藏态"只在 `<html class="has-js">` 时生效，**JS 挂了内容照样全部可见**
- 无障碍：完整支持 `prefers-reduced-motion: reduce`（淡入/光点/缩放自动关闭）；触屏不显示鼠标光点，原生光标保留
- 依赖：仅 `astro` 一个，全部免费开源，零花费

常用命令：

| 命令 | 作用 |
|---|---|
| `npm install` | 安装依赖（首次） |
| `npm run dev` | 本地预览，默认 <http://localhost:4321> |
| `npm run build` | 生成可部署的静态文件到 `dist/` |
| `npm run preview` | 本地预览构建后的成品 |
